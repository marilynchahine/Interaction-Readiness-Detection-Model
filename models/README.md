# Models

This folder contains the training, inference, and evaluation scripts for the interaction-readiness experiments.

The project includes three main settings:

- **Frame-based**: predict interaction readiness from one image.
- **Video-based, no rollout**: use 15 previous frames as visual context to predict frame 16.
- **Video-based, rollout**: use previous frames and earlier model predictions as context.

The model predicts, for each detected person:

```json
{
  "person_id": 1,
  "bbox": [x1, y1, x2, y2],
  "label": "interaction_ready"
}
```

The three labels are:

```text
not_interaction_ready
interaction_ready
interaction_ongoing
```

## Training Scripts

| Script | Purpose |
|---|---|
| `train/frameLevel_Qwen_LoRA_train.py` | LoRA fine-tuning for the frame-based model. |
| `train/videoLevel_Qwen_noRollOut_withPadding_LoRA_train.py` | LoRA fine-tuning for the temporal model using 16 raw frames without feeding previous predictions back to the model. |
| `train/videoLevel_Qwen_rollOut_withPadding_LoRA_train.py` | LoRA fine-tuning for the original rollout formulation with padding. |
| `train/videoLevel_Qwen_rollOut_noPadding_LoRA_train.py` | LoRA fine-tuning for the final rollout formulation. Predictions start at frame 16 and no padding is used. |

Training scripts save the final adapter under:

```text
OUTPUT_DIR/final_adapter/
```

---

## Prediction Scripts

| Script | Purpose |
|---|---|
| `predict/frameLevel_Qwen_ZeroShot_predict.py` | Frame-based zero-shot inference. |
| `predict/frameLevel_Qwen_LoRA_predict.py` | Frame-based inference using a trained LoRA adapter. |
| `predict/videoLevel_Qwen_noRollOut_withPadding_zeroShot_predict.py` | Video-based zero-shot inference using frames 1–15 as raw visual context and frame 16 as the target. |
| `predict/videoLevel_Qwen_noRollOut_withPadding_LoRA_predict.py` | Same no-rollout temporal pipeline using a trained LoRA adapter. |
| `predict/videoLevel_Qwen_rollOut_withPadding_zeroShot_predict.py` | Original rollout inference with padding at the beginning of videos. |
| `predict/videoLevel_Qwen_rollOut_withPadding_LoRA_predict.py` | LoRA version of the padded rollout pipeline. |
| `predict/videoLevel_Qwen_rollOut_noPadding_zeroShot_predict.py` | Final zero-shot rollout pipeline. Starts prediction at frame 16 and uses only real previous frames. |
| `predict/videoLevel_Qwen_GTrollOut_noPadding_zeroShot_predict.py` | Upper-bound diagnostic using ground-truth annotations in context frames. |

Prediction scripts generally produce:

```text
predictions.jsonl
```

which is used by the evaluation scripts.

## Evaluation Scripts

| Script | Purpose |
|---|---|
| `eval/FrameLevel_eval.py` | Evaluates frame-based predictions. |
| `eval/VideoLevel_noRollout_eval.py` | Evaluates video-based predictions without rollout. |
| `eval/VideoLevel_rollout_eval.py` | Evaluates rollout and upper-bound experiments. |

Evaluation uses IoU-based Hungarian matching.

A detection is considered correct when:

```text
IoU >= 0.50
```

Reported metrics include:

- localization Precision, Recall, and F1;
- classification Accuracy;
- Macro F1;
- Weighted F1;
- per-class metrics;
- confusion matrix.

Classification is evaluated only on accepted localization matches.

## Recommended Order

### Frame-Based Zero Shot

```bash
python models/predict/frameLevel_Qwen_ZeroShot_predict.py
python models/eval/FrameLevel_eval.py
```

### Frame-Based LoRA

```bash
python models/train/frameLevel_Qwen_LoRA_train.py
python models/predict/frameLevel_Qwen_LoRA_predict.py
python models/eval/FrameLevel_eval.py
```

### Video-Based Zero Shot Without Rollout

```bash
python models/predict/videoLevel_Qwen_noRollOut_withPadding_zeroShot_predict.py
python models/eval/VideoLevel_noRollout_eval.py
```

### Video-Based LoRA Without Rollout

```bash
python models/train/videoLevel_Qwen_noRollOut_withPadding_LoRA_train.py
python models/predict/videoLevel_Qwen_noRollOut_withPadding_LoRA_predict.py
python models/eval/VideoLevel_noRollout_eval.py
```

### Final Rollout

```bash
python models/predict/videoLevel_Qwen_rollOut_noPadding_zeroShot_predict.py
python models/eval/VideoLevel_rollout_eval.py
```

For LoRA rollout training:

```bash
python models/train/videoLevel_Qwen_rollOut_noPadding_LoRA_train.py
```

### Upper-Bound Diagnostic

```bash
python models/predict/videoLevel_Qwen_GTrollOut_noPadding_zeroShot_predict.py
python models/eval/VideoLevel_rollout_eval.py
```

## Input Data

Frame-based scripts use the balanced frame-level CSV generated using the scripts in annotation_scripts and manual modifications.

Temporal scripts use the 16-frame JSON groups generated by:

```text
annotation_scripts/group_by_16frames.py
```

The released dataset is available at:

https://huggingface.co/datasets/marilynchahine1/interaction-readiness-detection-dataset-frame-path-version

---

## Configuration

Most scripts use configuration variables defined directly at the top of the file.

Before running, update values such as:

```python
MODEL_NAME
INPUT_CSV
JSON_DIR
FRAME_ROOT
OUTPUT_DIR
LORA_CHECKPOINT
SPLIT
```

The paths currently present in the scripts are machine-specific and should be replaced with local paths.
